# School Management System

## Description

The School Management System is a Python object-oriented program that models people in a school.

It uses a parent `Person` class and child `Student` and `Teacher` classes to demonstrate inheritance. Students and teachers inherit common information such as name and age while also having their own attributes and behaviors.

## Features

- Stores a person's name and age
- Introduces a person
- Stores a student's major and student ID
- Records student study hours
- Changes a student's major
- Displays a graduation message
- Stores a teacher's subject and salary
- Allows teachers to grade assignments
- Allows teachers to assign homework
